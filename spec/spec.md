# ココロの羽 — 仕様書

## サービス概要

遠距離恋愛中の彼女が、不安・落ち込み・寂しさを感じた時にいつでも開ける、クローズドな私的Webサービス。

**サービス名**: ココロの羽  
**メインコピー**: どんなに遠く離れても  
**対象ユーザー**: 彼女（閲覧専用）、自分（管理・投稿）  
**公開範囲**: 完全クローズド（URL＋パスワード認証済みユーザーのみ）

---

## 技術スタック

| 項目 | 技術 |
|------|------|
| フレームワーク | Next.js (App Router) |
| データベース・認証 | Supabase (PostgreSQL + Supabase Auth) |
| 画像ストレージ | Supabase Storage |
| ホスティング | Vercel |
| スタイリング | Tailwind CSS |

---

## 認証設計

- Supabase Authを使用
- 彼女専用の1アカウントのみ存在（メールアドレスはダミー可）
- 彼女にはパスワードのみ伝える
- `/login`ページのみ未認証でアクセス可能
- それ以外の全ページはNext.jsミドルウェアでサーバー側チェックし、未認証なら`/login`にリダイレクト（HTMLすら返さない）
- セッションは長めに保持し、一度ログインしたら再入力不要にする
- 管理画面（`/admin`以下）も同じ認証を使用（同一アカウント）

## 画面構成

### 彼女側（閲覧画面）

#### `/login` — ログイン画面
- パスワード入力欄のみ（メールアドレス入力不要）
- パスワードの表示・非表示トグル
- 「ひらく」ボタン
- フッターに「いつでもここで待ってるから」（赤い糸 / コブクロ）

#### `/` — ホーム
- ヘッダー: サービス名「ココロの羽」＋ふわっと揺れるハートアニメーション
- TODAY セクション: 今日のひとこと（`today_message`テーブルの最新レコード）
- 新着メッセージ セクション: `messages`テーブルの直近3件（`created_at`降順）

#### `/letter` — 手紙
- サブタイトル: 「淋しい夜には、いつでも」（そばにいれるなら / コブクロ）
- カテゴリフィルター（横スクロール）: 「すべて」＋`categories`テーブルから動的取得
- メッセージ一覧: カテゴリで絞り込み、`created_at`降順
- 未読バッジ: 前回ログイン以降に追加されたメッセージに●表示

#### `/shelf` — 本棚
- サブタイトル: 「時の足音」（時の足音 / コブクロ）
- 3つのカードメニュー（思い出・好きなところ・日記）へのナビゲーション

#### `/shelf/memory` — 思い出
- サブタイトル: 「Million Films」（Million Films / コブクロ）
- 写真＋一言のカード一覧（`memory_date`降順）
- 写真はSupabase Storageの署名付きURLで表示

#### `/shelf/likes` — 好きなところ
- サブタイトル: 「ここにしか咲かない花、またひとつ」（ここにしか咲かない花 / コブクロ）
- `display_order`昇順で一覧表示
- 番号付きリスト（01, 02, 03…）

#### `/shelf/diary` — 日記
- サブタイトル: 「空見るたびに想う君のこと」（ココロの羽 / コブクロ）
- `diary_date`降順で一覧表示
- タイトル＋本文プレビュー（冒頭のみ）
- タップで全文表示（同ページ内展開 or 詳細ページ）

#### `/novel` — お楽しみ
- サブタイトル: 「One Song From Two Hearts」（One Song From Two Hearts / コブクロ）
- `created_at`降順で一覧表示
- タイトル＋冒頭プレビュー（`left(body, 100)`相当）
- タップで全文表示ページへ遷移

#### `/novel/[id]` — お楽しみ詳細
- タイトル＋全文表示
- 戻るボタン

### 管理画面（投稿・編集）

管理画面はPCでの利用を想定したデスクトップレイアウト。
左サイドバー＋メインコンテンツの2カラム構成。

#### `/admin` — 今日のひとこと
- 現在の表示内容を確認
- テキストエリアで更新（`today_message`テーブルのupdated_at更新）

#### `/admin/message` — メッセージ・手紙
- 投稿フォーム: カテゴリ選択（`categories`から動的取得）、タグ選択（`tags`から動的取得、複数選択可）、本文
- 一覧: カテゴリ・タグ・本文・投稿日表示、編集・削除ボタン

#### `/admin/memory` — 思い出
- 投稿フォーム: 日付、写真アップロード（Supabase Storageへ保存）、一言
- 一覧: 日付・一言・編集・削除ボタン

#### `/admin/likes` — 好きなところ
- 投稿フォーム: 一言テキスト
- 一覧: 番号・内容・削除ボタン（追加順に番号付与）

#### `/admin/diary` — 日記
- 投稿フォーム: 日付、タイトル、本文（テキストエリア）
- 一覧: 日付・タイトル・本文プレビュー・編集・削除ボタン

#### `/admin/novel` — お楽しみ（小説）
- 投稿フォーム: タイトル、本文（大きめのテキストエリア、数千字対応）
- 一覧: タイトル・投稿日・編集・削除ボタン

#### `/admin/analytics` — アクセス分析
- サマリー: 総アクセス数、今月のアクセス数、最もよく読まれたコンテンツ
- カテゴリ別閲覧数（横棒グラフ）
- 時間帯別アクセス（棒グラフ、Chart.js使用）
- コンテンツ別閲覧ランキング（全ページ横断、上位10件）
- 日別アクセスログ（日付ごとに折りたたみ式、ページ種別フィルター・期間フィルター付き）

#### `/admin/settings` — カテゴリ・タグ管理
- カテゴリ一覧: 名前・件数・編集・削除、新規追加フォーム
- タグ一覧: 名前・件数・編集・削除、新規追加フォーム（彼女画面には非表示の注記付き）

## セキュリティ要件

- 全ページ（`/login`を除く）はNext.jsミドルウェアで認証チェック
- 未認証リクエストはHTMLを返さずに`/login`へリダイレクト
- Supabase StorageはPrivateバケットとし、写真URLは署名付きURL（`createSignedUrl`）で取得
- 署名付きURLの有効期限: 1時間（ページ表示のたびに再取得）
- SupabaseのRLSにより認証済みユーザーのみDBアクセス可能
- 管理画面は彼女と同一アカウントで動作（管理者用の別アカウントは作成しない）
